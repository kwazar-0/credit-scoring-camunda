# Support

## How to get help

- **Bug reports and feature ideas:** use [GitHub Issues](https://github.com/OlehKondratow/credit-scoring-camunda/issues). Search existing issues first.
- **Questions and broader discussion:** [GitHub Discussions](https://github.com/OlehKondratow/credit-scoring-camunda/discussions), if enabled for the repository.
- **Contributing:** see [CONTRIBUTING.md](CONTRIBUTING.md) (branches, tests, style).
- **Security-sensitive issues:** do **not** use public issues; follow [SECURITY.md](SECURITY.md).

## Documentation

Project layout, runbooks, and naming are summarized in [README.md](README.md) and under **`docs-site/`** (e.g. [docs-site/git-workflow.md](docs-site/git-workflow.md), [docs-site/github-setup.md](docs-site/github-setup.md), [infra/ROLES.md](infra/ROLES.md)).

## Response times

Maintainers respond on a **best-effort** basis. There is no guaranteed SLA for this repository.

## Commercial support

This project is provided as open source under the [LICENSE](LICENSE). Commercial support, if any, is arranged outside this repository unless explicitly documented here.
