# Governance and Change Controls

## Roles and Segregation

- Access is role-based using the 11x6 governance model.
- Change approval and deployment execution are separated responsibilities.

## Git Workflow Controls

- Protected branches and mandatory pull request checks.
- CODEOWNERS-based review requirements.
- Release and production promotion approval records retained for audit.

## Access and Audit Evidence

- Environment access follows least-privilege model.
- Deployment events and approvals are retained as change evidence.
- Incident and rollback actions are documented with timestamps and owners.
