# Operations: Observability

## Logging

- Centralized structured logs in Cloud Logging.
- Correlation IDs propagated across API, Camunda, and workers.

## Metrics

- Golden signals: latency, traffic, error rate, saturation.
- Platform metrics: GKE node/pod health and workload saturation.
- Workflow metrics: Camunda incidents, retries, backlog, throughput.

## Alerting

- SLO-driven alerts with severity routing.
- Every alert links to a runbook entry for first response steps.
