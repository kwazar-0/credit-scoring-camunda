# Szablon tylko lokalny (kopiuj do accounts.local.md)

Skopiuj ten plik do `accounts.local.md` i uzupełnij **tylko na swojej maszynie**.
`accounts.local.md` jest w `.gitignore`.

```text
# user.name  user.email
Imię Nazwisko  twoj.email@example.com

# Opcjonalnie: forki / mirrory, które używasz lokalnie
# https://github.com/you/credit-scoring-camunda
```
