# Operations: Observability

## Logi

- Scentralizowane logi strukturyzowane w Cloud Logging.
- Correlation ID przechodzi przez API, Camunda i workery.

## Metryki

- Golden signals: latency, traffic, error rate, saturation.
- Metryki runtime GKE oraz Camunda (incidents, retries, backlog).

## Alerting

- Progi oparte o SLO z routingiem wg severity.
- Kazdy alert powinien prowadzic do runbooka.
