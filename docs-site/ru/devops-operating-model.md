# DevOps Operating Model

Этот проект управляется как production-платформа: с контролем поставки, эксплуатации и восстановления.

## Ключевые контуры

- CI/CD с обязательными quality/security gates.
- Развёртывание через GKE и версионированные релизные артефакты.
- Наблюдаемость и runbook-driven incident response.
