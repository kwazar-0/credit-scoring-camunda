# Operations: Observability

## Логи

- Централизованные структурированные логи в Cloud Logging.
- Correlation ID проходит через API, Camunda и worker.

## Метрики

- Golden signals: latency, traffic, error rate, saturation.
- Runtime-метрики GKE и метрики Camunda (incidents, retries, backlog).

## Алерты

- SLO-driven пороги с маршрутизацией по severity.
- Каждый алерт должен вести на runbook.
