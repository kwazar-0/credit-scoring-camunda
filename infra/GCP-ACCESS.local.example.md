# Пример заполнения — скопируйте в `GCP-ACCESS.local.md` (файл в .gitignore)

Удалите этот пример в продакшн-репозитории, если не нужен; или храните только локально.

```text
# Проекты
PROJECT_DEV=my-dev-project
PROJECT_STAGING=my-staging-project
PROJECT_PROD=my-prod-project

# Группы
GROUP_PLATFORM=gg-millennium-platform@example.com
GROUP_DEVELOPERS=gg-millennium-developers@example.com
# ...
```

Сопоставьте с таблицей в [GCP-ACCESS.md](GCP-ACCESS.md).
