# Observability

## Logging

- Structured logs to Cloud Logging.
- Correlation ID propagation across API, Camunda, and workers.
- Log-based metrics for workflow and worker failure classes.

## Metrics

- Golden signals for API and workers.
- Camunda runtime metrics (incidents, retries, backlog, throughput).
- GKE runtime metrics (node pressure, restart rates, saturation).

## Alerting

- SLO-driven alert rules with severity routing.
- Runbook link is required for each paging alert.
